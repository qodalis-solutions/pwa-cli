Qodalis CLI — настоящая командная строка в вашем телефоне. Введите команду и нажмите Enter: более 100 команд выполняются прямо на устройстве, работают без интернета и не требуют онлайн-аккаунта.

ИНСТРУМЕНТЫ НА КАЖДЫЙ ДЕНЬ
• guid, hash (SHA-1/256/384/512), base64, hex, url, jwt decode, binary и morse
• generate-password для надёжных случайных паролей
• qr превращает любой текст или ссылку в изображение QR-кода
• Графики и Markdown прямо в терминале
• Инструменты для regex, json и csv, а также для текста: upper, camelCase, slug, pad, replace и другие
• cal, метки времени, расписания cron, lorem ipsum и случайные числа
• Список дел, секундомер и таймер обратного отсчёта
• curl и wget для HTTP-запросов, speed-test для проверки соединения

ФАЙЛЫ И РЕДАКТОР NANO
• ls, cd, mkdir, cat, cp, mv, rm, tree, find, grep, sed, awk, sort, head, tail и wc
• Редактируйте любой файл во встроенном редакторе nano
• Конвейеры, алиасы, переменные окружения, поиск по истории и автодополнение по Tab
• Ваши файлы сохраняются на устройстве между сеансами

ИГРЫ, А С PKG — ЕЩЁ БОЛЬШЕ
• 2048, Тетрис, Змейка, Сапёр, Судоку и Wordle — касаниями или с клавиатуры
• pkg browse показывает дополнительные пакеты, а pkg add устанавливает любой за секунды
• Скоро: «Четыре в ряд», «Виселица», «Пятнашки» и Mastermind

ВАШ ТЕЛЕФОН В КОМАНДНОЙ СТРОКЕ
• device, battery и network показывают, что происходит с телефоном
• share отправляет вывод любой команды в другое приложение; vibrate и toast — для ваших скриптов

СОЗДАНО ДЛЯ СЕНСОРНЫХ ЭКРАНОВ
• Ряд клавиш с Esc, Tab, Ctrl+C, Ctrl+L, стрелками и символами, которые прячут мобильные клавиатуры
• Ввод без автокоррекции: команды приходят ровно такими, какими вы их набрали
• Короткая экскурсия при первом запуске покажет главное
• Темы, настраиваемый размер шрифта и 11 языков: английский, немецкий, испанский, французский, итальянский, японский, корейский, португальский, румынский, русский и китайский

ВАШИ ДАННЫЕ ОСТАЮТСЯ У ВАС
Ваш аккаунт, файлы и задачи хранятся только на вашем устройстве. Приложение выходит в интернет только для команд, которым это нужно, например curl или speed-test, и для показа рекламы. Анонимная статистика использования помогает улучшать приложение; отключить её можно командой analytics off.

Qodalis CLI — бесплатное приложение с открытым исходным кодом на основе веб-терминала Qodalis: https://cli.qodalis.com
