Qodalis CLI は、スマートフォンに本物のコマンドラインを届けます。コマンドを入力して Enter を押すだけ。100 以上のコマンドが端末上で直接動き、オフラインでも使え、オンラインアカウントは不要です。

毎日使えるツール
• guid、hash（SHA-1/256/384/512）、base64、hex、url、jwt decode、binary、morse
• 安全なランダムパスワードを作る generate-password
• qr でテキストやリンクを QR コード画像に変換
• グラフと Markdown をターミナルで表示
• regex、json、csv のツールと、upper、camelCase、slug、pad、replace などの文字列ツール
• cal、タイムスタンプ、cron スケジュール、lorem ipsum、乱数
• ToDo リスト、ストップウォッチ、カウントダウンタイマー
• HTTP リクエスト用の curl と wget、回線速度を測る speed-test

ファイルと nano エディター
• ls、cd、mkdir、cat、cp、mv、rm、tree、find、grep、sed、awk、sort、head、tail、wc
• 内蔵の nano エディターでどんなファイルも編集
• パイプ、エイリアス、環境変数、履歴検索、Tab 補完
• ファイルはセッションをまたいで端末に保存されます

ゲーム、そして pkg でもっと
• 2048、テトリス、スネーク、マインスイーパー、数独、Wordle をタッチでもキーボードでも
• pkg browse で追加パッケージを一覧表示、pkg add で数秒でインストール
• コネクトフォー、ハングマン、15 パズル、マスターマインドも近日登場

コマンドラインからスマホを操作
• device、battery、network でスマホの状態を確認
• share でコマンドの出力を他のアプリへ送信。スクリプトには vibrate と toast

タッチ画面のために設計
• Esc、Tab、Ctrl+C、Ctrl+L、矢印キー、スマホのキーボードでは隠れがちな記号を並べたキー列
• 自動修正なしの入力で、コマンドは打ったとおりに届きます
• 初回起動時の短いツアーで基本をご案内
• テーマ、文字サイズの調整、11 言語に対応：英語、ドイツ語、スペイン語、フランス語、イタリア語、日本語、韓国語、ポルトガル語、ルーマニア語、ロシア語、中国語

データは手元に
アカウント、ファイル、ToDo は端末にのみ保存されます。アプリがインターネットに接続するのは、curl や speed-test など通信が必要なコマンドを実行したときと、広告を表示するときだけです。匿名の利用統計はアプリの改善に役立ちます。analytics off でオフにできます。

Qodalis CLI は無料のオープンソースで、Qodalis の Web ターミナルフレームワーク上に作られています：https://cli.qodalis.com
